Comment obtenir ton token GitHub :
1. Va sur GitHub → ton profil → Settings
2. Developer settings → Personal access tokens → Fine-grained tokens
3. Clique Generate new token
4. Choisis uniquement ce repo, permission Contents → Read and Write
5. Copie le token (commence par github_pat_…)

⚠️ Ne partage ce token avec personne. Il est stocké uniquement dans ta session de navigateur et disparaît à la fermeture.
Token invalide ou accès refusé. Vérifie les permissions du token.
